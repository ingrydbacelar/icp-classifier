## Sobre o projeto

O **ICP Website Analyzer** foi desenvolvido para facilitar a análise de sites de empresas, utilizando critérios relacionados ao **Perfil de Cliente Ideal (ICP)** para apoiar a identificação e qualificação de potenciais clientes.

## Funcionalidades

* Análise de websites
* Identificação de informações relevantes da empresa
* Avaliação de aderência ao ICP
* Processamento de diferentes sites
* Organização dos resultados
* Interface web intuitiva

## Tecnologias

* Python
* FastAPI
* JavaScript
* HTML5
* CSS3
